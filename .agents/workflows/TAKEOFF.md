# NEWXAU Takeoff Workflow

1. Read root instructions, memory index, current state, and handoff.
2. Stop rather than inventing work when no active handoff/objective and no current user task exists.
3. Inspect tracked, staged, and untracked Git state and compare files with the handoff.
4. Verify claims through code and tests.
5. Continue only the next safe task.
6. Do not inherit unverified assumptions.
7. Update or clear the handoff after progress.
