# NEWXAU Handoff Workflow

1. Inspect status (including untracked files), unstaged diffs, and staged diffs.
2. Read current state and active handoff.
3. Update `docs/ai/HANDOFF.md` from verified facts.
4. Include execution, database, model/submodule, and session/timezone safety state.
5. Run the memory checker.
6. Return a concise transfer summary.
