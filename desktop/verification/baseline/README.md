# Pre-Electron migration baseline

This directory is generated by:

```powershell
python scripts/export_desktop_baseline.py
```

It freezes the REST routes, WebSocket route/event catalog, environment-variable
surface, and SHA-256 hashes of execution-sensitive and legacy-dashboard files.
Secret values are never read or exported.

The canonical source revision is tag `pre-electron-migration`.
The exporter refuses to overwrite an existing baseline unless `--force` is
passed; re-baselining requires explicit approval.

Visual captures and test evidence are recorded separately because they require a
running application and a validated runtime.

The checked-in visual evidence is:

- `../screenshots/legacy-dashboard.png`
- `../screenshots/desktop-overview.png`

Both captures were produced with background workers and Capital.com execution
disabled.
